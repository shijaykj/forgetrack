| Phase | Deliverable | Done when |
|---|---|---|
| A | Research + spec + architecture + this plan | Docs in `/docs` |
| B | Domain types, zod schemas, calculations, exercise library, persisted store, sample-data generator | Unit tests pass |

## Status (v1.0)

All phases A–F are implemented. Verified: unit tests (19), `tsc` strict, ESLint, production build; manual browser QA of the routine → log → PR → finish → history loop, rest timer persistence across reload, picker search/multi-select, bodyweight logging, history edit/delete/undo, light/dark themes, and no horizontal overflow on every route at 360 px; layouts checked at 360, 375, 800 and 1440 px.

## v1.1 — iPhone app
- Capacitor 8 iOS shell (`ios/`, SPM, no CocoaPods); `npm run ios`, `ios:sync`, `ios:run`.
- `src/lib/native.ts` platform bridge: Taptic haptics, locked-screen rest notifications, status bar theming, keep-awake (native + web Wake Lock), share-sheet export, Files-app data mirror with auto-restore.
- PNG icon set (web, PWA maskable, iOS 1024) + splash generated by `scripts/gen-icons.mjs`; portrait-only on iPhone; no input auto-zoom.
- Test setup shim for Node 25+'s non-functional `localStorage` global (repo moved to macOS / Node 26).

## v1.2 — Gym-floor extras
- Plate calculator (animated barbell, bar weight per unit, "use for next set") and plates-per-side chip on barbell/EZ/Smith lifts; warm-up ramp generator with undo (`domain/plates.ts`, 10 tests).
- Live Activity (lock screen + Dynamic Island) for the live workout and rest timer — verified on the iOS 26.1 simulator.
- Apple Health: opt-in, write-only HKWorkout (traditional strength training) on finish — verified saving on the simulator.
- Not done: iCloud backup — needs a paid Apple Developer Program team (the iCloud entitlement can't be signed with a free Apple ID). Deleting a workout in ForgeTrack does not remove it from Health.

Next candidates: verify on a physical iPhone; iCloud Drive backup (paid account); Live Activity buttons (skip/+30 s) via App Intents; programs & auto-progression; RPE/RIR.

Deferred (see README / final summary): cloud sync & multi-device, plate calculator & warm-up generator, programs with auto-progression, RPE/RIR, wearables, health-platform export, e2e test suite.

Decisions taken autonomously:
- Greenfield Vite SPA (repo was empty) instead of a server framework — self-hosting is a static folder.
- No authentication: single-user local-first app; "User" is a local profile. Multi-user sync deferred.
- Hand-rolled SVG charts for originality and bundle size.
- Supersets modeled as exercise links, not a per-set type.
